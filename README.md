## Формат текстового файла (`data/figures.txt`)
Каждая строка — одна фигура. Разделитель — точка с запятой `;`.
- Круг: `Circle;радиус`
- Прямоугольник: `Rectangle;ширина;высота`

## Структура
- `geometry2d`, `geometry3d` — классы фигур
- `exceptions` — собственные исключения
- `storage` — интерфейс и реализации (текстовая, бинарная)
- `app` — сценарий запуска (`Main.java`)
- `data` — примеры файлов для чтения
